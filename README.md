# 日常调查

这是一个专门记住日常的长期记忆插件：慢慢了解对方几点上班、平时怎么吃饭、有哪些习惯、最近在忙什么。记忆在后台积累，相关时回想，也可以留一点自然好奇。

**人格提示词和短期情绪决定是否好奇、是否问候、怎样说话。** 本插件不规定亲密程度，不要求热情，也不要求每轮关心或追问。没有相关日常时，前台不追加日常提示。

## 安装与开始

需要 AstrBot **4.29.4 或更新的 4.x、Python 3.12+**，以及已配置的聊天模型。

1. 在 AstrBot 插件管理中，通过仓库链接 `https://github.com/1972124398/astrbot_plugin_daily_routine` 安装；也可从文件安装版本 ZIP。
2. 启用「日常调查」，正常聊天即可。例如：“我工作日九点到六点上班”“最近改上夜班了”。
3. 默认停聊 45 秒后后台整理；也会在累计 6 条或等待 10 分钟后整理。用 `/日常调查` 或 `/routine` 查看自己的画像。
4. 如需后台主动联系，在配置中打开「允许后台私聊主动问候与日常好奇」并选择目标私聊。默认只在聊天里按话题取用，不会自动发私聊。

依赖由 AstrBot 安装，无需额外数据库或服务。[下载版本](https://github.com/1972124398/astrbot_plugin_daily_routine/releases)。

## 会了解哪些日常

工作或上课、通勤、用餐、睡醒、固定空闲时段、夜班、临时加班与休假，以及生活偏好、平时活动和时间尚不明确的日常习惯。

- 有明确时间才形成用于判断时机的区间；只知道“最近很忙”时保留文字，不编造上下班时间。
- 工作日、休息日与指定星期分别记录；夜班跨过午夜时，归属于开始上班的那一天。
- “今天加班”应只在对应日期有效；“以后改成夜班”可以替换之前的班次。实际提取依赖后台模型，记录中保留原话依据。
- 不根据消息出现的时间推断已经起床、下班或睡着；不会把 Codex 报告、AI 自己的消息和游戏结果当成用户新作息。
- 作息超过默认 120 天未被确认后，停止用于时机判断，原记录仍可查看。普通聊天不会自动给旧作息续期。
- 没有起止时间的安排也能记成文字，不必先补齐字段；时间明确后可更新同一条认识。发生改变时保留至多三条较早说法，平时使用当前认识，聊以前时才顺带回想。
- “今天加班”这样的文字近况也保留有效日期。过期后不再当成现状；问起之前的事情时仍能回想，问明天的安排也能按日期查看。

后台会参考最近最多六轮真实问答，帮助理解“六点左右”“周末再说”等省略回答。例如 AI 刚问几点下班，对方回答“六点左右”，可以记住下班时间，但不会凭空补出上班时间。跨批次只参考一天内的这些片段；新事实的依据仍须来自本次真人发言，AI 自己的猜测不能成为事实。

聊天只召回与当下话题相关的少量记忆。例如问几点睡觉时，优先回想睡眠习惯，不因为数据库里先存了饮食就把早餐也带进来。写代码、讲故事等无关交流不会因为正好处于工作时间就额外收到作息提示。

每份画像按 **会话、人格、发送者账号** 分开保存。昵称只作显示，群里每个人有独立记录；不把一个人的睡眠时段当成全群免打扰。

默认只收集实际进入 AI 对话的真人发言，不监听所有未唤醒机器人的群聊。记录是日常了解，不是完整聊天记录库。

## 问候只是一种机会

根据已知作息，可以提示上班前、下班后、睡前与醒来后的问候。不了解睡眠安排时，使用宽泛的早晚机会。有具体睡眠安排后，以个人作息为准，夜班人群不会被固定早八点问早。

中国节假日和调休可通过内置日历库参考，非中国日常可以关闭。日历库没有覆盖的年份，退回星期安排，不猜农历节日。节假日名称只在这一段假期的开始日提供问候机会，不每天重复节日问候；有明确“工作日”安排时可参考调休，但不会据此宣称这个人一定放假。额外节日可在配置写 `12-25=圣诞节` 或 `2026-12-01=特别的日子`。

前台问候只在间隔至少半小时后重新打招呼时提供；正在连续聊天或带着具体任务回来时，不因到点了就插入早安晚安。同一机会在 AI 完成一次考虑后不再反复提示。**考虑过不等于已经问候**；它可以接着原话题，也可以完全不说。

可选主动问候仅用于已聊过的私聊。默认至少相隔 8 小时，7 天没有真人交流则停止；发出后未得到回复，不继续发送日常问候。模型可返回 `WAIT`，不会套用固定问候语作为兜底。当前有聊天、游戏或其他主动发言占用注意力时先等一等。发送没有确认时也不连续重试。

## 一点主动好奇

好奇来自具体的相处，不是补齐信息的问卷。例如对方说“最近每天都加班”，按当前人格，AI 可以留下一点“这周能不能歇一歇”的念头；也可以觉得没什么想问的。

后台至多保留一个念头，不增加一条专门的模型调用。只有话题相关、或重新见面打招呼时，才给前台一个很短的参考。说不说、问不问、用什么方式问，仍由当下人格和情绪决定。已经考虑过后，至少隔三天才再考虑日常好奇；改个说法或换个 key 不会绕过这段间隔。念头超过两周未更新便不再提示。

回答已得到、对方不想谈或情况变了，后台可以放下念头。前台即使没有问，也不会因为没完成收集而下一轮继续催。可以在配置中单独关闭「允许留下日常好奇」。

主动私聊开启后，这个念头也可以成为一次可选主动联系的缘由，与问候共用现有目标、间隔和无回复等待机制，不另起一套调度。没有早晚问候机会时，也可以因一件以前聊过的事自然开口，或继续安静。

## 与现有七个插件的关系

所有联动均可选，未安装时继续独立运行。配置有联动总开关与每个相关插件的独立开关。

| 现有插件 | 分工与联动 |
| --- | --- |
| 自主认知（长期记忆） | 后台整理与主动问候可参考对应人格的长期背景；新增作息仍以本人实际发言为依据。长期主动联系也可参考作息，日常主动说过的话可留下共同经历。 |
| 短期共享情绪 | 主动问候读取当前情绪并调用现有情绪提示接口；聊天中的情绪仍由原插件提供。日常调查不修改任何情绪值或风格设定。 |
| 陪它玩 | 选择主动邀玩对象时参考个人时段，规划也可读作息摘要。用户主动开玩、继续游戏和出招照常。 |
| 自娱自乐 | 选择主动搭话对象时参考个人时段，后台规划可以了解日常背景，自己已经发出的消息会让日常问候先等回应。 |
| Codex Bridge | 共享现有主动发言间隔，并识别后台报告来源。任务报告不计作真人活动，不修改或延迟任务处理。 |
| 主动表情 | 日常调查不决定表情、表达方式或发送顺序；表情继续由原插件按人格与心情选择。 |
| 微信原生表情转图片 | 继续负责输入转换，无需专门接口，也不会把表情转换结果推断成个人作息。 |

配套版本：**陪它玩 0.3.3、自娱自乐 0.5.1、自主认知 0.10.3**。从日常调查 0.1.0 升级到 0.2.0 只需更新本插件，已有数据继续使用，配套插件无需再次更新。旧版 companion v1 插件可以读取部分背景；实际减少主动触发需要上述配套版本。热加载或卸载时会撤销本插件登记的背景读取入口。

联动快照只提供简短的时段背景，不通过其他插件再次塞入完整画像、问题或问候机会，避免多个插件重复引导同一件事。

已知工作时段的主动触发系数为 0.15，忙碌 0.1，通勤 0.4，用餐 0.6，睡眠 0，未知或空闲为 1。系数只作用于**后台主动候选**，不会拦截用户对话。半小时内保持同一次时机判断，避免频繁轮询反复抽中。各插件自身的目标、频率、免打扰和人格决策继续有效。

## 命令

命令只管理当前发送者在当前会话、当前人格下的画像。

| 命令 | 用途 |
| --- | --- |
| `/routine` 或 `/日常调查` | 查看日常条目、条目 key、可选好奇、待整理数量与后台状态 |
| `/routine_set work 09:00 18:00 workday` | 手动设置工作日工作区间，替换已有 work 区间 |
| `/routine_set sleep 23:00 07:00 any` | 设置每日跨夜睡眠区间 |
| `/routine_set work 22:00 06:00 0,1,2,3,4` | 设置周一至周五开始的夜班；0 是周一，6 是周日 |
| `/routine_forget key` | 删除对应条目，同时放下当前待整理片段，避免旧结果写回 |
| `/routine_control pause` / `resume` | 暂停或恢复自己的记录与背景提示 |
| `/routine_control clear` | 清空自己的画像及待整理片段 |
| `/routine_contact off` / `on` | 关闭或允许自己的日常主动联系（问候与好奇）；on 仍需全局开启并选择目标 |

区间类型：`work` 工作/上课、`sleep` 睡眠、`meal` 用餐、`commute` 通勤、`free` 空闲、`busy` 忙碌、`other` 其他安排。日期类别可用 `any` 每天、`workday` 工作日、`restday` 休息日，或逗号分隔的星期数字。日常纠正也可直接聊天，无需先学命令。

## 后台与数据

数据在 AstrBot 数据目录 `data/plugin_data/astrbot_plugin_daily_routine/routines.json`，实际位置由 `StarTools.get_data_dir` 决定。画像、依据、待整理队列和个人开关会保留；升级插件代码不会覆盖它们。

实时请求只收集文本并读取内存，不等待磁盘、后台模型或长期记忆检索。后台异步保存，失败退避重试；共用模型时新聊天会取消正在等待的整理，原片段保留待下次继续。使用独立 Provider 可减少资源争用。后台模型仍会消耗所选 Provider 的资源。

尚未整理的输入片段保存至处理成功；整理后保留日常条目与证据原话，以及最多六轮用于理解省略回答的短问答、一个可选好奇念头。片段会发送给配置的模型 Provider。删除条目会同时放下待整理片段、这几轮上下文和好奇，避免旧结果把已删除的事重新带回来。备份可在停止 AstrBot 后复制整个插件数据目录。

本插件没有单独的网页面板，配置使用 AstrBot 原有配置页，个人查看和修正通过上述命令完成。
